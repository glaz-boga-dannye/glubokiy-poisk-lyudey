## Чем глубокий поиск отличается от обычного

Обычный запрос помогает быстро проверить конкретный номер, ник или профиль. Глубокий поиск подключает дополнительные базы, в том числе непубличные, и сводит сведения из них в один отчёт. По информации команды сервиса, эти базы обновляются чаще. Поэтому в расширенном поиске могут появиться связи, которых не было в обычном результате.

Отчёт показывает, сколько записей и баз участвовало в поиске. Состав полей зависит от того, что нашлось по вашему запросу.

## С чего можно начать

В меню бота откройте «Глубокий поиск» и выберите тип запроса: ФИО, номер телефона, email, ИНН, соцсеть или кадастровый номер. Для соцсети подойдёт Telegram-ник либо ссылка на профиль ВК, Instagram или TikTok. Если вы начали со страницы соцсети, бот сначала ищет связанный номер, а затем использует его для расширенного отчёта.

Например, поиск по ФИО может дать телефон и почту. Дальше по этим признакам можно увидеть связанные аккаунты и другие записи о человеке. Если у вас уже есть номер, начните с него: в одном отчёте удобнее рассмотреть связи номера с именами, адресами и профилями.
